##Customer Support Ticket Priority Prediction and Automated Assignment System Using Agentforce
A Salesforce-based system that automatically analyzes customer support tickets and classifies them as High, Medium, or Low priority.
#Features
- 🎫 Support ticket management
- 🤖 Agentforce-based ticket analysis
- ⚡ Automatic priority prediction
- 👨‍💼 Automated support assignment
- 🚨 Urgent task creation for High-priority tickets
- 📊 SLA risk checking
#Technologies
Salesforce | Agentforce | Salesforce Flow | Custom Object
#Workflow
Customer Ticket → Agentforce → Analyze Description → Priority Prediction → Assignment → Task Creation → Response
#⚡ Salesforce Flow
#The Auto-Launched Flow:
1. Gets the customer account.
2. Retrieves the latest support ticket.
3. Analyzes the ticket description.
4. Sets the priority.
5. Creates a task for High-priority tickets.
6. Assigns the appropriate support level.
7. Returns the final response.
#🚨 Example
Customer: "My application is not working."
System:
Priority → High
Assignment → Senior Support Agent
Task → Urgent Ticket Handling
#✨ Key Benefits
- Faster ticket processing
- Automatic priority prediction
- Reduced manual work
- Better handling of urgent issues
- Improved support-ticket management
